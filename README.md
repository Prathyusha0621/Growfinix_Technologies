# Growfinix Technologies – Internship Tasks

This repository contains my completed tasks for the Growfinix Technologies Internship.

## Completed Tasks

### Task 1 – Real Estate Market Data Cleaning
- **Tools:** Excel, Power Query
- Cleaned and standardized real estate property data.
- Removed duplicates and handled missing/inconsistent values.
- Merged property data with historical sales data.
- **Folder:** `Task-1-Data_Cleaning`

### Task 2 – Sports Analytics & Performance Metrics
- **Tools:** MySQL
- Analyzed IPL match data for Kolkata Knight Riders.
- Calculated venue-wise win rates and average run rates.
- Used JOIN, GROUP BY, CTEs and Window Functions.
- **Folder:** `Task-2-Sports_Analytics`

### Task 3 – Customer Demographic Analysis
- **Tools:** Python, Pandas, Matplotlib, Google Colab
- Performed exploratory analysis of tour enquiry data.
- Analyzed popular travel destinations, age groups and income brackets.
- Created charts and visualizations.
- **Folder:** `Task-3-Customer_Demographic_Analysis`
