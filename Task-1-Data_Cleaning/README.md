# Growfinix Task 1 – Data Cleaning

## Project Overview

This project was completed as part of the Growfinix Technologies internship program.

Task 1 focuses on cleaning and transforming real-estate property data using Microsoft Excel and Power Query.

## Objective

- Clean and transform property data
- Remove duplicate records
- Handle missing and inconsistent values
- Merge property data with historical sales data
- Create a clean final dataset

## Tools Used

- Microsoft Excel
- Power Query
- GitHub

## Key Operations

- Data cleaning
- Data validation
- Duplicate checking
- Data transformation
- Data merging using `Property_ID`
- Left Outer Join
