# Growfinix Technologies – Task 1
## Data Cleaning and Transformation using Excel Power Query

### 1. Project Overview

This project was completed as part of the Growfinix Technologies internship program.

The objective of Task 1 was to clean, transform, and prepare property and historical sales data using Microsoft Excel and Power Query.

### 2. Objective

The main objectives of this task were:

- Clean raw property data.
- Remove duplicate records.
- Handle missing and inconsistent values.
- Transform the data into a structured format.
- Merge property data with historical sales data.
- Use Property_ID as the common key.
- Produce a clean final dataset suitable for analysis.

### 3. Tools Used

- Microsoft Excel
- Power Query
- GitHub

### 4. Data Sources

The project used two main datasets:

- Raw_Property_Data
- Historical_Sales_Data

### 5. Data Cleaning

The raw data was processed using Power Query.

The following operations were performed:

- Checked the dataset structure.
- Cleaned and transformed columns.
- Checked for duplicate records.
- Checked for missing values.
- Standardized the data.
- Prepared the datasets for merging.

### 6. Data Merge

The `Raw_Property_Data` table was merged with the `Historical_Sales_Data` table.

The common column used for the merge was:

`Property_ID`

The join type used was:

`Left Outer`

This ensured that all records from the property dataset were retained while matching historical sales information where available.

### 7. Data Validation

After the cleaning and transformation process:

- Duplicate records were checked.
- Data consistency was reviewed.
- The merged dataset was inspected.
- The final output was loaded into Excel.

### 8. Final Output

The final cleaned and transformed dataset was successfully prepared in Microsoft Excel.

The output can be found in the Excel project file included in this repository.
