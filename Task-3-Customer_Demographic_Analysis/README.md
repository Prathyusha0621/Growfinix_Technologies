# Growfinix Task 3 – Customer Demographic Analysis

## Objective
Analyze customer demographic data from tour enquiries using Python, Pandas, and Matplotlib.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
The dataset contains 2,000 tour enquiry records with the following fields:
- Customer_ID
- Age
- Income
- Income_Bracket
- Destination

## Analysis Performed
- Dataset structure and statistical summary
- Most popular travel destinations
- Customer distribution by age group
- Customer distribution by income bracket
- Average income by income bracket
- Age distribution histogram
- Missing-value check
- Duplicate-record check

## Key Findings
- Goa was the most popular destination with 341 customers.
- The 26–35 age group had the highest number of customers.
- Lower-Middle income customers formed the largest income bracket.
- No missing values were found.
- No duplicate records were found.

## Visualizations
Bar charts and a histogram were created using Matplotlib to present the analysis results.

## Conclusion
The analysis provides insights into customer age, income, and travel preferences and helps identify the most popular destinations and major customer demographic groups.
